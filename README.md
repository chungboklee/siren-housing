# 사이렌 주거

사이렌의 공통 약속은 놓치면 아까운 정보를 제때 알려주는 것입니다. 사이렌 주거는 청년 월세·이사비·전세임대 공고부터 시작합니다. 월세 공제처럼 같은 독자가 주거비를 해결하는 데 필요한 주제를 이어서 다룰 수 있습니다. 일반 연말정산은 별도 제품 후보로 둡니다.

## 로컬 실행

Node.js 22 이상에서 의존성 설치 없이 실행합니다.

```sh
npm run build
npm run preview
```

브라우저에서 `http://127.0.0.1:4173/`를 엽니다. `dist/`는 빌드 결과입니다.

## 공고 갱신

`data/notices.json`에 공식 원문과 날짜를 기록합니다. 접수 시각은 한국 시간 오프셋을 포함합니다. 시각을 확인할 수 없는 일정은 날짜만 입력하고 상세에서 공식 접수 시간을 확인할 수 있게 안내합니다. `verifiedOn`은 원문을 마지막으로 확인한 날입니다. 게시할 내용이 달라진 경우 `updatedOn`도 변경합니다. 같은 공고의 정정은 기존 주소에 반영하고 다른 모집 회차에는 새 주소를 부여합니다.

`region`에는 광역 지역을, `municipality`에는 해당하는 경우 시·군·구를 기록합니다. 마감일이 명시되지 않은 경우 `closes`를 `null`로 두고 `availability`에 `check` 또는 `closed`를 기록합니다. 예산 소진 등으로 실제 접수 여부를 확인할 수 없으면 `check`, 공식 접수처에서 종료를 확인하면 `closed`를 사용합니다. 조건과 확인 출처는 상세 페이지에 남깁니다.

`npm run build`를 다시 실행하면 상세 페이지, 전체·서울·부산 RSS, 사이트맵이 생성됩니다. 접수 상태는 이미 등록된 공고의 날짜를 기준으로 브라우저에서 한국 시간으로 계산합니다. 신규·정정 공고는 공식 원문을 확인한 뒤 데이터를 직접 갱신하고 배포합니다. 정기 수집 작업은 연결되어 있지 않습니다.

## 공개 빌드

`SIREN_SITE_URL`에 실제 HTTPS 주소를 설정한 뒤 빌드하면 해당 주소로 RSS와 사이트맵을 생성하고 페이지에 canonical URL을 넣습니다. 주소를 설정하지 않은 미리보기 빌드는 검색 색인을 차단합니다. `wrangler.jsonc`는 Cloudflare Workers 정적 자산 배포에 사용합니다.

`SIREN_EMAIL_SUBSCRIBE_URL`에 실제 이메일 서비스의 HTTPS 구독 주소를 설정하면 구독 링크가 표시됩니다. 파일럿 운영비는 0원이며, V1 운영비 목표는 월 10만 원 이내입니다. 도메인 구매비는 별도입니다.
